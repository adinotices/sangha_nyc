# sangha.nyc

Website for the young adult sangha of the New York Insight Meditation Center.

Single-page static site (`index.html`), deployed to GitHub Pages via GitHub Actions on every push to `main`.


## Local preview

Just open `index.html` in a browser, or serve the directory:

```
python3 -m http.server 8000
```

## Placeholders to fill in

Search the page for `class="placeholder"` — these mark details still needing real values (sit day/time, room number, contact info, event dates, social links).
